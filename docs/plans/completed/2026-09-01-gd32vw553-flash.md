# GD32VW553 烧录支持

**日期：** 2026-09-01
**Spec:** `docs/specs/completed/2026-09-01-gd32vw553-flash-design.md`

## Goal

让 tyutool 的 CLI 与 GUI 都能烧录和擦除 GD32VW553：协议从 `tmp/gd32/gd32_1.pcapng`
还原，实现落在 `tyutool-core` 的插件层，其余各层只做登记。读取不做（loader 没有该
命令）。

## Architecture

两级下载：ROM bootloader（57600 8E1，只负责把 RAM loader 写进 SRAM 并跳转）→ RAM
loader（115200 8N1 握手，协商到传输波特率后擦除、按 2560 字节带地址的 XMODEM 帧写入、
SHA-256 校验、复位）。详见 spec。

## Tech Stack

Rust（`tyutool-core` 插件 + `serialport`），新增 `sha2` 直接依赖（已在 workspace lock
里，与既有的 `md-5` 同族）；前端只改 manifest 与文案。

## 风险

单次抓包的推断集中在擦除/校验两条命令的字段宽度上（spec「观测 vs 推断」一节）。
若实机上擦除或校验行为异常，先怀疑这两处的编码，而不是流程。
