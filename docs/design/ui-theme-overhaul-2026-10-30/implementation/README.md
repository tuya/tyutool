# Precision Workbench 正式界面实施验收

分支：`yj/ui-theme-overhaul`。基于 `4ae3f0d96d85eebe65dc63a386a8781d88dbc5c4` 实施，按主题基础、固件、串口、批量工具、设置和验收证据拆分提交。

推荐的石墨深色与纸白浅色已落实到正式 Vue 应用：统一导航、标题、连接栏、控件、日志、历史、弹窗、任务状态与设置分组。主要操作使用薄荷青，警告使用琥珀色，错误与破坏性操作使用红色。主题切换同步 DaisyUI，与已有系统偏好和持久化保持一致。

页面扫描检查了实际文字与不透明/透明背景叠色，当前可见非禁用文字没有低于对应文字对比度阈值的候选；日志级别文字另有实际组件对比度回归。扫描不覆盖渐变、祖先透明度、ANSI 用户自定义颜色、所有悬停状态或辅助技术，因此不代表完整的无障碍认证。

## 查看与复查

启动正式应用开发服务：

```bash
pnpm run dev:web
```

没有硬件后端也可用 Vite 检查界面；正式运行仍按应用提供的端口与能力显示实际状态：

```bash
pnpm exec vite --host 127.0.0.1 --port 1430 --strictPort
```

正式页面入口与截图画廊：

```text
http://127.0.0.1:1430/flash
http://127.0.0.1:1430/docs/design/ui-theme-overhaul-2026-10-30/implementation/gallery.html
```

在已有依赖和 Chromium 的环境中重新生成正式界面证据：

```bash
node docs/design/ui-theme-overhaul-2026-10-30/implementation/verify.mjs
node docs/design/ui-theme-overhaul-2026-10-30/implementation/capture-states.mjs
node docs/design/ui-theme-overhaul-2026-10-30/implementation/verify-gallery.mjs
```

脚本默认连接 1430，可用 `TYUTOOL_UI_BASE_URL` 指定已有服务地址。页面脚本生成 40 张截图；状态脚本生成 48 张截图。画廊支持这两份指标中的组合，重新截图不需要重新生成画廊；画廊检查脚本验证全部 88 张图片、组合切换、小窗口布局和直接打开本地文件。

回归测试由 Playwright 配置启动服务；执行前让 1430 端口空闲：

```bash
pnpm run test:ui:confirmed
pnpm run test:coverage
pnpm run lint
pnpm run typecheck:scripts
pnpm run typecheck:ui
pnpm run check:tauri-versions
pnpm run build
```

本次本地回归复用了已有 Vite，通过临时 Playwright 配置设置 `reuseExistingServer: true`；仓库的端口占用策略未改变。

## 验证边界

截图来自正式生产组件，端口、日志、任务状态、更新清单与诊断 IPC 使用本地测试数据；`99.0.0` 是演示版本。状态脚本没有执行烧录、授权、下载或安装。浏览器回归验证了 UI 与已有 store 交互，Rust 测试验证了对应软件逻辑。

本轮未完成原生 Tauri WebView、系统文件选择/导出、读屏软件和真实串口设备验收。原生文件操作、系统字体与实际设备通信需在目标桌面环境复核；浏览器与 Rust 测试通过不等同于这些验收通过。
