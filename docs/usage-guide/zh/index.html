tyutool 使用指南

欢迎使用 tyutool — 涂鸦类 IoT 设备的固件烧录与调试工具。

tyutool 是一款桌面 GUI + 命令行工具，用于对涂鸦类（Tuya-class）IoT 设备进行固件烧录、串口调试与批量授权。本指南面向零基础用户，图文并茂，按章节循序渐进地介绍每个功能。

从这里开始 第一次使用？请先阅读 快速上手，5 分钟完成下载、安装并烧录第一个设备。

固件烧录

选择芯片与固件，一键烧录到设备。

串口调试

实时收发串口数据，查看设备日志。

设置

配置路径、日志级别等应用选项。

批量烧录授权

批量处理多台设备的烧录与授权。

命令行

无界面环境下使用 tyutool 命令行。
