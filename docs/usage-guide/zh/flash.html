固件烧录

本页是 /flash 页面的完整参考：连接栏、Flash / Erase / Read / Authorize 四个标签、芯片清单表、多段烧录、擦除预设，以及右侧的进度与日志。

1. 页面总览

打开 /flash 页面后，整个界面由三部分组成：

  • 顶部连接栏：选择串口、波特率、芯片型号，并显示连接状态。
  • 左侧/中部操作卡片：四个标签 —— Flash（烧录）、Erase（擦除）、Read（读取）、Authorize（授权）。
  • 右侧进度与日志：实时显示当前操作的分阶段进度和滚动日志。

2. 连接栏

连接栏位于页面顶部，集中了所有与设备链路相关的控件：

  • 串口（Serial port）：下拉列出系统当前可用的串口；每次打开下拉时会重新扫描串口列表，避免插拔后列表过期。
  • 波特率（Baud）：提供常用档位 115200 / 460800 / 921600 / 1000000 / 1500000 / 2000000，以及 custom（自定义，范围 300–4,000,000）。在 Authorize（授权）标签下，这里设置的是授权波特率而非烧录波特率。
  • 芯片选择器（Chip selector）：选择目标芯片型号；在 Authorize 标签下会额外多出一个 other（仅授权）选项。
  • 状态点：用颜色指示当前串口连接状态（已连接 / 未连接 / 占用中）。
自动连接 / 自动释放 启动一项操作时，如果串口尚未连接，tyutool 会自动连接所选串口；操作完成后会自动释放该端口，便于其他程序（或串口调试页）接管。

关于擦除对齐 所有芯片在擦除时都要求 4 KiB 对齐（起止地址必须是 0x1000 的整数倍）；仅授权专用的 other 芯片豁免——它没有可烧录的 flash。这一点在下方 擦除标签会再次提及。

4. Flash 标签 — 烧录

Flash 标签用于把固件写入 flash。它支持多段烧录：你可以一次性把多份固件写到不同的地址段，例如先写 bootloader 再写 app。

段（segment）表格最多支持 10 段，每段包含：

  • 固件路径：支持 .bin / .hex / .elf / .img 等格式。
  • 起始地址（start） 与 结束地址（end）：十六进制。

段与段之间会自动衔接：

  • 点击“添加段（add segment）”时，新段的起始地址默认等于上一段的结束地址，省去手动输入。
  • 为某一段选择固件文件后，结束地址会自动计算为 start + 文件大小。

只有当所有段都已填入固件路径时，Flash 按钮才会启用；任一段缺少路径时按钮保持禁用。

多段烧录的典型场景 最常见的用法是“bootloader + app”：第一段写引导程序（地址较低），第二段写主应用。一次性写入可以避免分两次操作、中间忘记切换地址导致的覆盖事故。

5. Erase 标签 — 擦除

Erase 标签用于擦除 flash 中的指定区域。提供两种擦除方式：

  • 按地址擦除：输入起始（start）和结束（end）地址（十六进制），界面会实时校验对齐。
  • 高级 — 擦除预设（Advanced）：按芯片型号提供预设范围，具体见上方芯片清单表（authInfo / fullChipNoRf / fullChip，并非每款芯片都全部具备）。

擦除预设（erase preset）的含义：

预设类型含义
authInfo只擦除授权信息区（UUID/AuthKey），保留固件与其他数据。
fullChipNoRf整片擦除但保留射频校准区（RF cal），避免设备无法连网。
fullChip整片完全擦除，所有区域一律清空（含射频校准）。

执行擦除前会弹出确认对话框。如果所选芯片要求 4 KiB 对齐而你输入的范围不对齐，对话框会说明原因并提供一个“对齐（align）”操作，它会自动改写起止地址到最近的合法对齐边界后再执行。

危险：擦除会破坏数据 擦除会把目标区域清空为 0xFF，不可撤销。整片擦除尤其会清空射频校准（RF cal），可能导致设备刷完后无法连网。重要内容请先用 Read 标签备份。

6. Read 标签 — 读取

Read 标签用于把 flash 内容读出来存成文件，是备份的主要手段：

  • 保存目录：在 Tauri 桌面端选择一个保存目录；在网页端则是浏览器下载。
  • 文件名：默认为 tyutool_read_<chip>.bin（例如 tyutool_read_t5ai.bin）。
  • 结束地址：默认取该芯片的完整 flash 容量（见芯片表），即默认做整片读取。

如果目标文件已存在，会弹出对话框让你选择：覆盖（Overwrite） 还是 追加时间戳（Append-timestamp）（即文件名后自动加上时间后缀，避免覆盖旧文件）。

7. Authorize 标签 — 授权

Authorize 标签用于 TuyaOpen UART 授权，写入设备上云凭据（UUID + AuthKey）：

  • UUID 与 AuthKey 输入框：内容会被掩码显示，且不允许复制，以防凭据泄露。
  • 复制凭据（Copy credentials） 按钮：在受控场景下把当前凭据复制出来。
  • 页面提供指向 TuyaOpen 授权购买 与本地化授权文档的外部链接。

授权分两种操作：

  • 读取授权（Read Auth）：仅探测设备当前的 UUID/AuthKey，只占用串口，不写入任何内容。
  • 授权（Authorize）：执行写入，需要先填好 UUID 与 AuthKey。执行前会有确认提示流程。
凭据请妥善保管 UUID 与 AuthKey 是从涂鸦购买的凭据，写入伪造或重复的值会导致设备无法上线甚至污染设备池。请勿在截图、日志、聊天中泄露凭据。此外，other 芯片仅支持授权，没有 flash 插件，无法烧录。

8. 进度与日志

页面右侧是一个常驻的进度 + 日志面板：

  • 分阶段进度条：按操作阶段（phase）显示进度，每个阶段有自己的主题色、当前百分比；对于无法预估进度的阶段会显示不确定（indeterminate）状态。
  • 日志面板：滚动显示操作日志，提供 锁定自动滚动（lock auto-scroll）、清空（clear）、复制（copy） 三个控件。

9. 端口占用

固件烧录页与串口调试页共用同一批串口。两者不能同时占用同一个端口。

端口被占用时 如果串口调试页当前正占用某个端口，在烧录页操作该端口时，tyutool 会请你先释放它；你也可以在串口调试的设置里开启自动释放（auto-release），让它在其他页面需要时自动让出端口。详见 串口调试页。
