批量授权 · 操作员指南

本页写给使用 tyutool 进行批量烧录授权的操作员：怎么准备、怎么操作、出了问题怎么办。不需要任何技术背景。

走错页了？ 如果你是固件开发者（需要知道固件要实现哪些功能才能被批量授权），请看 批量授权 · 固件开发者必读。

1. 这个工具做什么

把很多台设备一次性处理完——只要把多块设备插到电脑的多个串口上，点一下按钮，tyutool 就会同时给它们烧录固件并写入上网所需的授权码。授权码不是你手动敲的，而是从一份 Excel 表格里自动一行行读取。

只能在桌面应用里用 这项功能依赖电脑硬件能力，只能在桌面版 tyutool 里使用，网页版不可用。

2. 开始前要准备什么

  • 桌面版 tyutool：确保装的是桌面应用，不是网页版。
  • 授权码 Excel 表（.xlsx）：这是从涂鸦购买来的授权码。表格至少要有两列：UUID 和 AuthKey（列名不区分大小写）。其余列 tyutool 会自动补充状态、MAC、时间等。
  • 设备 + 串口线：把要处理的设备用 USB 转串口线接到电脑，每台设备占一个串口。
  • 串口驱动：装好 USB 转串口芯片的驱动（CH340 / CP2102 / FT232 等），否则电脑看不到串口。
  • 要烧录的固件（可选）：如果这一步还要刷固件，准备好固件文件（.bin），或使用 tyutool 提供的官方授权固件下载。
授权码很贵重 UUID 和 AuthKey 是花钱买来的凭据，一码对应一台设备。请妥善保管 Excel 文件，不要泄露到聊天、截图里。

3. 第一次进入

第一次打开批量授权页时，会弹出一个免责声明对话框，提醒你这功能涉及不可逆的操作。确认你理解后点继续即可进入页面。如果勾选了“不再提示”，下次就不会再弹；点取消会退回工具箱，不进入页面。

4. 一次完整操作怎么走

  1. 选芯片型号：按你设备的芯片选（例如 esp32、t5ai；如果只授权不烧录可选 other）。
  2. 设波特率：烧录波特率和授权波特率分别设置；不确定就用默认值。
  3. 选固件（仅当需要烧录时）：开关打开“烧录固件”，选本地 .bin，或用“默认”从官方下载授权固件（按芯片过滤、可选版本、显示下载进度）。
  4. 选授权码 Excel 表：选中后界面立即显示 总数 / 已用 / 进行中 / 剩余。确认“剩余”大于 0——否则启动按钮会保持禁用。
  5. 设置冲突策略：遇到已带授权的设备是跳过还是覆盖。
  6. （仅 T5AI）选存储模式：KV（可重写）或 OTP（写一次不可逆，详见 安全须知）。
  7. 自动分配端口：点“自动分配”，把所有可用串口加为处理插槽。
  8. 启动：点“启动”开始整批处理。空闲端口较多（> 8）时会弹确认框，避免误启动。
  9. 看仪表盘等完成：实时看烧录/授权的累计统计、当前批次进度；整批结束会有完成横幅（全部成功 / 全部失败 / 部分成功 / 全部跳过）。
  10. 核对结果：逐行检查每个端口的状态，失败的可以点错误看详情并重试。
想先探一下设备现状？ 点工具栏的“全部读取”，会对非活动插槽做只读探测（读 MAC、读现有授权），不写入任何内容，适合批量前摸底。

5. 看懂结果

每个参与处理的端口占一行，你会看到这几样东西：

  • 状态徽标（带颜色）：告诉你这行当前是什么情况。常见状态如下：
状态什么意思
done（完成）这台设备烧录和授权都成功了，是好品。
failed（失败）某一步出错了。点错误信息看详情，可以重试。
skipped（跳过）这台设备已经有授权，按你设的“跳过”策略跳过了。
no_code（无码）授权码用完了，没分到码给这台设备。
其他（处理中）显示“正在读取/正在烧录/正在授权”等都属于还在处理，等它跑完即可。
  • 进度条：烧录阶段会显示分阶段进度。
  • MAC / UUID：读取到后会显示在这行。
  • 错误信息：失败时显示；点开可看详情并复制，方便报问题。

6. 出错了怎么办

端口没出现 / 打不开

  • 换一根 USB 线、换一个 USB 口（很多问题是线材或接触不良）。
  • 确认串口芯片驱动已装好（CH340 / CP2102 / FT232）。
  • 关掉其他正在用串口的程序（其他串口调试软件、Arduino IDE 等），它们可能占着端口。
  • 更多排查见 常见问题 · 连接/端口。

全部失败 / 大量失败

  • 先用单台设备试通，确认整个流程跑通，再投入整批。
  • 把波特率调低（例如降到 115200），高波特率下丢包会让失败激增。
  • 供电不足也会导致批量失败——检查 USB 口供电，必要时换外接供电。

Excel 报错（被占用 / 无效）

  • 提示“文件被占用”：先关掉 Excel / WPS再重新选表。批量运行期间 tyutool 会锁住文件防止冲突。
  • 提示表无效：检查表里是否确实有 UUID 和 AuthKey 两列，且 UUID/AuthKey 长度正确。

想看更详细的日志 / 报问题

失败的详细信息在每行的错误对话框里；如果需要更深入排查，参考 常见问题 · 如何反馈 bug 导出日志。

7. 安全须知

批量授权是 tyutool 里唯一会触发不可逆硬件操作的功能。请记住下面两条：

铁律一：OTP 模式写一次不可逆 如果存储模式选了 OTP（仅 T5AI 可选），授权码会一次性烧进芯片，永远无法擦除或修改。一旦配错（芯片型号错、固件错、授权码错），整批设备都会被毁掉。所以：用 OTP 之前，务必先用一台设备把整个流程完整跑通验证，确认无误后再批量。
铁律二：出现“已写入后取消”危险徽标的设备必须单独放一边 如果某台设备在授权可能已经写入之后才被取消，它会显示一个物理隔离危险徽标——意思是授权可能已经写进去了，设备状态不确定。这种设备不能当成好品，也不要直接重新跑批量，必须单独拿出来核实清楚后再决定怎么处理。
批量前的检查清单 启动整批前，逐项确认：芯片型号对、固件版本对、授权表已校验且“剩余”够、冲突策略符合预期；用 OTP 的话务必先单台验证。
