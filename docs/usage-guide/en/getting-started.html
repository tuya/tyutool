Getting Started

This page walks you from "downloaded the app" all the way to "successfully flashed my first device." The path is linear — read it in order and you will have completed your first flash in about 5–10 minutes.

Read first If you have never flashed firmware before, start with Concepts.

Prerequisites

Before you start, confirm everything on this checklist is ready — flashing needs both hardware and software in place.

  • A supported device: tyutool targets Tuya-class IoT devices; the full list of supported chips is on the Firmware Flash page.
  • A USB-serial adapter: wired correctly to the device's UART (TX/RX/GND, optionally power). Wiring must cross over: the PC side's TX goes to the device's RX, and vice versa.
  • The device in bootloader/download mode: how to enter it varies per device (button combos, bridging test pads, power sequencing).
Note Wiring and entering download mode are device-specific — there is no universal procedure, so check your device's manual or the FAQ first. tyutool cannot put a device into download mode for you; you must do it yourself. When the device is not in download mode, tyutool waits for a handshake and eventually times out. For the underlying concepts (UART / download mode / baud rate), see Concepts.

Download & install

tyutool ships prebuilt installers for Windows, macOS, and Linux. Go to the README download table, pick the build for your operating system, and install it the usual way. The common per-platform gotchas are below (full details in the FAQ).

macOS Gatekeeper On first launch of an unsigned app, macOS blocks it as "cannot be verified." Run xattr -dr com.apple.quarantine /path/to/tyutool.app in a terminal to strip the quarantine flag, then launch. See the FAQ.
macOS serial permission macOS denies ordinary users access to serial devices by default. Add your user to the dialout group: sudo dseditgroup -o edit -a $USER -t user dialout, then log out and back in for it to take effect. See the FAQ.
Linux blank window On some Linux desktops the tyutool window comes up blank. Launch it as WEBKIT_DISABLE_COMPOSITING_MODE=1 tyutool to work around it. See the FAQ.
Tip All three platform quirks are environment issues, not tyutool bugs; once resolved they generally do not recur.

First launch

After installing, launch tyutool. The main window has two parts: a navigation sidebar on the left and the active feature's workspace on the right. The sidebar exposes four main destinations:

  • Flash — flash, read, and erase the flash chip.
  • Serial Debug — send and receive serial data in real time, inspect device logs.
  • Toolbox — a collection of helper tools.
  • Settings — configure paths, log level, and other app options.

The rest of this page stays entirely on the Flash page — it is the only destination you need for your first flash.

Connect your device

Once the wiring checks out and the device is in download mode, establish the connection in tyutool as follows.

  1. Plug the USB-serial adapter into a USB port on your PC.
  2. On tyutool's Flash page, click the Serial port dropdown.
  3. Pick your adapter from the listed ports (e.g. COM3 / /dev/ttyUSB0 / /dev/cu.SLAB_USBtoUART).
  4. Watch the status dot next to it: green means connected and ready; grey or red means no connection or failed handshake.

Once a port is chosen, tyutool auto-suggests a sensible default baud rate and chip model; in most cases you can accept them, and you can override manually if needed.

Tip If the dropdown shows no ports at all, confirm the adapter is plugged in and its driver is installed (CH340/CP2102/FT232), and recheck macOS/Linux serial permissions (see the install section above).

Your first flash

With the device connected, the flash itself is short. Walk through these steps in order to write your first firmware.

  1. Pick the chip model: at the top of the Flash page, select the chip that matches your device (the model decides the protocol and address layout; a wrong choice fails to flash).
  2. Choose the firmware: on the Flash tab, choose a firmware file and pick a .bin firmware.
  3. Confirm addresses: after selecting firmware, the write addresses auto-fill with defaults that you usually do not need to change.
  4. Click Flash: hit the Flash button to start writing.
  5. Watch progress: keep an eye on the progress bar and the log below it; a healthy run climbs steadily to 100%.
  6. Wait for reboot: when the write finishes, the device automatically reboots running the new firmware — your first flash is now complete.

For the advanced options behind each step (address tweaks, erase strategy, verification, saving logs), see the Firmware Flash page.

Important While flashing, do not unplug the USB cable or cut power — doing so can corrupt the data. If a flash fails, first drop to 115200 baud and retry; if it still fails, see the FAQ.
