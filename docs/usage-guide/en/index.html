tyutool Usage Guide

Welcome to tyutool — the firmware flashing and debugging tool for Tuya-class IoT devices.

tyutool is a desktop GUI + command-line tool for flashing firmware, debugging the serial port, and batch authorization of Tuya-class IoT devices. This guide is written for zero-base users, is image-rich, and walks through every feature step by step.

Start here First time? Begin with Getting Started — download, install, and flash your first device in 5 minutes.
