# UI 细节与性能复核

本轮在 `yj/ui-theme-overhaul` 上复核展示、键盘交互和重复计算。改动集中在前端组件与 composable；串口协议、归档、原始字节、设备所有权和历史持久化逻辑保持原实现。

## 已确认并修复

| 场景 | 原问题 | 修改后的行为 |
| --- | --- | --- |
| 诊断日志搜索 | 搜索 `&` 会破坏 HTML 实体，显示 `&amp;`；`<device>` 命中后没有高亮 | 先匹配原文，再逐段转义，保留原始显示文本和安全的高亮 |
| 日志阅读 | 连续空格、制表符被折叠；初次搜索仍停在旧滚动位置 | 保留空白布局，首次搜索将首个结果滚入视野 |
| 发送历史方向键 | 选中项更新，焦点却留在上一条；随后 Enter 会选回上一条 | 列表内焦点随选中项移动；搜索框内仍保留输入焦点和 Enter 填入行为 |
| 下拉框动态更新 | 选项重排、移除或禁用后，活动项可能指向错误条目；整个控件禁用后浮层仍打开 | 按选项值同步活动项，跳过禁用项，清除失效的活动项及提示，禁用时关闭浮层 |
| 中文输入确认 | IME 输入中的 Enter 可能触发下拉选择 | 输入法组合期间不处理选择按键 |
| 历史日期 | 编辑名称时对每条记录重新创建日期格式器 | 缓存格式器与日期文本；语言切换时更新 |
| 设置滚动与烧录日志 | 同一批事件多次测量布局、写入滚动位置 | 设置导航按动画帧合并；烧录日志在一次 DOM 更新后统一跟随尾部 |
| 浮层定位 | 浮层内部滚动也会测量锚点；外部连续事件反复定位 | 内部滚动不重定位，外部滚动及 resize 按帧合并；关闭和卸载取消待执行工作 |
| 批量耗时 | 空闲、完成后仍每秒唤醒；重新进入已完成批次时先显示占位符 | 开始、完成和重试立即更新耗时，仅运行中的批次保留计时器 |
| 诊断日志重复解析 | 每次搜索重做分行、等级识别和大小写转换，每行创建正则 | 随文件内容缓存解析结果，每次搜索只创建一个字面量匹配正则 |

## 受控场景测量

| 场景与指标 | 修改前 | 修改后 | 验证方式 |
| --- | ---: | ---: | --- |
| 100 条历史记录，编辑一次名称：`Intl.DateTimeFormat` 构造次数 | 101 | 0 | Chromium 构造器计数 |
| 同一批 100 次设置滚动事件：布局读取次数 | 606 | 6 | Chromium `getBoundingClientRect` 计数 |
| 同步追加 100 条烧录日志：滚动高度读取及位置写入次数 | 各 101 | 各 1 | 组件回归中的 getter/setter 计数 |
| 浮层内两次滚动：锚点测量次数 | 2 | 0 | composable 回归 |
| 同一帧 100 次外部滚动和 100 次 resize：锚点测量次数 | 200 | 1 | composable 回归；浏览器验证修改后为 1 |
| 批量工具空闲时：耗时计时器数量 | 1 | 0 | 隔离 interval 的假时钟回归 |

这些数字衡量指定事件批次中的重复工作，不代表整体速度提升比例或实机帧率。浏览器另验证了历史列表实际滚动后不测量锚点、外部事件合并后仍可正确定位。

## 验证结果

- 修复前回归已复现日志、下拉框、烧录滚动、历史焦点、日期格式化、设置布局读取、浮层测量及批量计时问题。
- `pnpm run test:coverage`：86 个文件、1191 项通过；statements 84.87%、branches 78.16%、functions 89.04%、lines 85.74%。最终测试兼容性及定位断言调整后，相关 5 项再次通过。
- 完整已确认浏览器回归：135 项通过，包含中英文、明暗主题、1280×800 与 1024×680 页面布局，以及历史、ASCII/Hex、复制、弹窗焦点、浮层翻转、窗口缩放和滚动恢复。
- 人工复核了明亮主题日志及历史截图，暗色主题最小窗口下的固件工具、批量工具、长指令预览及日志高亮截图。
- lint、scripts/UI 类型检查、构建、Tauri 版本一致性检查通过。构建仍输出 Vite 原生配置扩展名和动态导入提示，成功退出。
- Rust fmt、全部 workspace 成员的 clippy/test、`ts-rs` 与 bindings drift，以及 `zip,excel,mock-chip,record-io,download` 特性组合的 clippy/test 均通过。
- tsx IPC 与 Rust 回环监听最初被沙箱阻止；在允许相应本地 IPC/监听的环境中重跑成功，无需修改测试或产品代码绕过限制。

## 验证边界

浏览器使用模拟的串口、归档和 Tauri 调用。Rust 集成测试包含本地回环与软件伪串口证据；本轮未运行原生 Tauri 窗口验收、物理串口设备或长期硬件压力测试。没有为了追求性能重写串口虚拟列表、原始字节或归档分页链路。
